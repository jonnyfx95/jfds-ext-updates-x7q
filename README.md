# jfds-ext-updates-x7q

Repository tecnico usato solo come canale di aggiornamento self-hosted per
un'estensione browser interna (Firefox, `browser_specific_settings.gecko.update_url`).

Non contiene codice sorgente ne' dati sensibili — solo un `updates.json`
(update manifest Mozilla) e i pacchetti `.xpi` firmati delle versioni
pubblicate. Non c'e' nulla da eseguire o installare a partire da questo repo.
